# DayZ configuration input

Place XML and JSON files that you want GitHub Actions to validate in this directory. Preserve whatever subdirectory layout helps identify mission files.

Do not add Nitrado tokens, FTP credentials, private keys, IP allowlists, or other secrets. A private repository is still not a substitute for GitHub Actions Secrets.

Version 1 validates XML/JSON syntax and well-formedness. It does not claim semantic Central Economy validation.
